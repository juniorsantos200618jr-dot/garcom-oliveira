# Garcom Facil — MVP Android v2

Versao com painel administrativo dentro do proprio app.

## O que esta versao faz
- Login simples de garcom.
- 20 mesas.
- Cardapio por categorias (Bebidas, Churrascos, Porcoes etc.).
- Painel administrativo dentro do app.
- Adicionar, editar, desativar e apagar produtos.
- Editar nome, preco e categoria de cada produto.
- Escolher em qual setor cada item imprime: churrasqueira, cozinha ou bar.
- Produtos e alteracoes ficam salvos no celular com SharedPreferences.
- Carrinho, observacoes e envio de pedido.
- Fila de producao por setor.
- Impressao ESC/POS por IP/TCP porta 9100.
