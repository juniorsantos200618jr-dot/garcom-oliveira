## O que entrou nesta versao
- Login real por usuario e senha local.
- Somente o Administrador ve o painel administrativo.
- Administrador pode criar, editar, ativar/desativar e excluir acessos de garcons.
- Cada garcom tem nome, usuario e senha proprios.
- Ao fazer pedido, o nome do garcom fica registrado na mesa/pedido.
- Administrador consegue ver nas mesas quem esta atendendo.
- Cardapio editavel continua disponivel no painel administrativo.
- Configuracao simplificada para uma unica impressora.
- Botao de teste de impressao.
- IP/porta da impressora ficam salvos no celular.

## Observacao
Os acessos ainda sao armazenados localmente no aparelho para esta fase. Para varios celulares compartilharem os mesmos usuarios, mesas e pedidos em tempo real, sera necessario ligar o app a um banco online numa etapa seguinte.
