GARCOM FACIL - GERAR APK USANDO SO O CELULAR

O projeto ja inclui codemagic.yaml para o Codemagic gerar o APK automaticamente.

Fluxo:
1. Crie uma conta no GitHub pelo navegador do celular.
2. Crie um repositorio chamado garcom-facil.
3. Envie TODO o conteudo deste projeto para o repositorio.
4. Entre no Codemagic e conecte sua conta GitHub.
5. Escolha o repositorio garcom-facil.
6. O Codemagic deve reconhecer o arquivo codemagic.yaml.
7. Rode o workflow "Gerar APK Android".
8. Ao finalizar, abra Artifacts e baixe o arquivo app-release.apk.
